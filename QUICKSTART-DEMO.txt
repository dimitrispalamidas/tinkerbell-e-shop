=====================================
VIVA WALLET SETUP
=====================================

Για να λειτουργήσουν οι πληρωμές:

1. Δημιούργησε Viva Wallet demo account:
   https://developer.viva.com/demo-accounts/

2. Πάρε API credentials από το portal

3. Πρόσθεσέ τα στο .env.local:
   VIVA_API_URL=https://demo-api.vivapayments.com
   VIVA_CLIENT_ID=your_client_id
   VIVA_CLIENT_SECRET=your_secret
   VIVA_SOURCE_CODE=1234
   VIVA_WEBHOOK_KEY=random_string

4. Test Cards (Demo):
   ✅ Success: 4111 1111 1111 1111
   ❌ Fail: 4000 0000 0000 0002

Για αναλυτικές οδηγίες: VIVA-WALLET-SETUP.txt

=====================================
ΟΤΑν ΠΑΡΕΙΣ BOXNOW CREDENTIALS
=====================================

1. Βάλε τα στο .env.local:

   # Stage (για testing)
   BOXNOW_API_URL=https://api-stage.boxnow.gr
   BOXNOW_OAUTH_CLIENT_ID=stage_id
   BOXNOW_OAUTH_CLIENT_SECRET=stage_secret
   BOXNOW_DEFAULT_ORIGIN_ID=stage_warehouse

2. Restart το app:
   npm run dev

3. Τώρα:
   ✅ Θα φορτώνει ΠΡΑΓΜΑΤΙΚΑ lockers από BOXNOW
   ✅ Θα δημιουργεί delivery requests (stage - δεν στέλνει)
   ✅ Θα βλέπεις parcels στο Partner Portal
