===========================================

--------------

2. pnpm package manager
3. Stripe account (for payments)
4. Supabase project (already configured via MCP)

STRIPE SETUP:
-------------
1. Create a Stripe account at https://stripe.com
2. Get your test API keys from the Dashboard
3. Set up a webhook endpoint:
   - URL: http://localhost:3000/api/webhooks/stripe
   - Events to listen for: payment_intent.succeeded, payment_intent.payment_failed
   - Copy the webhook secret to STRIPE_WEBHOOK_SECRET

RUNNING THE APP:
----------------
1. Install dependencies:
   pnpm install

2. Run the development server:
   pnpm dev

3. Open http://localhost:3000 in your browser

DEFAULT ROUTES:
---------------
Customer-facing:
- Homepage: http://localhost:3000 (or /el, /en)
- Shop: /el/katastima or /en/shop
- Cart: /el/kalathi or /en/cart
- Checkout: /el/oloklirosi or /en/checkout
- Gallery: /el/gallery/baptism, /el/gallery/decorations

Admin:
- Login: http://localhost:3000/admin/login
- Dashboard: /admin
- Products: /admin/products
- Orders: /admin/orders
- Gallery: /admin/gallery

CREATING AN ADMIN USER:
-----------------------
1. Sign up a user through Supabase Auth
2. Add the user to the admin_users table:
   INSERT INTO admin_users (user_id, role) 
   VALUES ('user-id-from-auth', 'admin');

DATABASE:
---------
The database is already set up with the following tables:
- products: Store product catalog
- categories: Product categories (clothing, shoes)
- orders: Customer orders
- order_items: Individual items in orders
- gallery_items: Baptism and decoration showcase images
- admin_users: Admin user permissions
