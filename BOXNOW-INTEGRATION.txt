    access_token: "...",

  Headers: Authorization: Bearer {token}
  Body: {
    typeOfService: "standard" | "same-day",
    orderNumber: "order_123",
    paymentMode: "prepaid" | "cod",
    allowReturn: true,
    origin: {
      locationId: "warehouse_id"
    },
    destination: {
      locationId: "locker_id",
      contactName: "...",
      contactNumber: "...",
      contactEmail: "..."
    },

      name: "Order #123",
      compartmentSize: 1 | 2 | 3  // 1=small, 2=medium, 3=large
    }]
  }
  Response: {
    id: "parcel_id",
    trackingNumber: "..."

=====================================
TROUBLESHOOTING
=====================================

Πρόβλημα: Το widget δεν φορτώνει
---------------------------------
✓ Έλεγξε ότι έχεις βάλει το NEXT_PUBLIC_BOXNOW_PARTNER_ID στο .env.local
✓ Έλεγξε το Network tab - το script φορτώνει;
✓ Έλεγξε το Console - υπάρχουν JavaScript errors;
✓ Βεβαιώσου ότι υπάρχει το <div id="boxnowmap"></div>

Πρόβλημα: Θέλω stage widget για testing
----------------------------------------
✓ Το widget επικοινωνεί ΜΟΝΟ με production by default
✓ Για stage widget, στείλε email στο: ict@boxnow.gr
✓ Ζήτησε: "Stage/sandbox widget for testing"
✓ Θα σου δώσουν ειδικό configuration ή URL

Πρόβλημα: Error "_bn_map_widget_config is required"
----------------------------------------------------
✓ Το config ΠΡΕΠΕΙ να οριστεί ΠΡΙΝ φορτώσει το script!
✓ Σειρά: 1) Ορίζεις _bn_map_widget_config, 2) Φορτώνεις το script
✓ Στο Next.js: Βάλε το config σε useEffect χωρίς dependencies που τρέχει πρώτο
✓ Το Script component με strategy="afterInteractive" θα φορτώσει μετά

Πρόβλημα: Error "Parent element #boxnowmap not exist"
------------------------------------------------------
✓ Το div με id="boxnowmap" ΠΡΕΠΕΙ να υπάρχει ΠΡΙΝ φορτώσει το script!
✓ Αν το div είναι conditional (π.χ. σε step 2), το script πρέπει να φορτώνει conditional
✓ Λύση 1: Φόρτωσε το script ΜΟΝΟ όταν το div υπάρχει
✓ Λύση 2: Έχε το div hidden αλλά να υπάρχει πάντα στο DOM
✓ Στο Next.js: Wrap το <Script> με το ίδιο condition με το div

Πρόβλημα: Το widget φορτώνει αλλά δεν λειτουργεί το afterSelect
----------------------------------------------------------------
✓ Έλεγξε ότι το _bn_map_widget_config έχει οριστεί σωστά
✓ Έλεγξε το Console για errors
✓ Βάλε console.log() μέσα στο afterSelect για debugging

Πρόβλημα: API Error 401 (Unauthorized)
---------------------------------------
✓ Τα OAuth credentials είναι λάθος
✓ Το CLIENT_ID ή CLIENT_SECRET είναι λανθασμένο
✓ Δοκίμασε να ξαναφέρεις τα credentials από το BOXNOW
✓ Έλεγξε ότι χρησιμοποιείς το σωστό API_URL (stage vs production)

Πρόβλημα: Δεν δημιουργείται delivery request
---------------------------------------------
✓ Έλεγξε τα webhook logs (console logs με 📦)
✓ Έλεγξε ότι το NEXT_PUBLIC_BASE_URL είναι σωστό
✓ Έλεγξε ότι υπάρχει boxnow_locker_id στην παραγγελία
✓ Έλεγξε ότι έχεις βάλει το BOXNOW_DEFAULT_ORIGIN_ID

Πρόβλημα: API Error 400 (Bad Request)
--------------------------------------
✓ Έλεγξε το request body format
✓ Έλεγξε ότι το BOXNOW_DEFAULT_ORIGIN_ID είναι σωστό
✓ Έλεγξε ότι το locker ID είναι valid
✓ Κοίτα το error message για λεπτομέρειες

=====================================
OAUTH2 AUTHENTICATION FLOW
=====================================

Το BOXNOW API χρησιμοποιεί OAuth2 Client Credentials flow:

1. Το service ζητάει access token με το CLIENT_ID & CLIENT_SECRET
   → POST /api/v1/auth-sessions

2. Το BOXNOW επιστρέφει access token (ισχύει 1 ώρα)
   → { access_token: "...", expires_in: 3600 }

3. Το access token χρησιμοποιείται σε όλα τα API requests
   → Authorization: Bearer {token}

4. Το token ανανεώνεται αυτόματα όταν λήξει
   → In-memory caching με expiration check

=====================================
COMPARTMENT SIZES
=====================================

Όταν δημιουργείς delivery request, επιλέγεις compartmentSize:

1 = SMALL   (Μικρό πακέτο)
2 = MEDIUM  (Μεσαίο πακέτο) - DEFAULT
3 = LARGE   (Μεγάλο πακέτο)

Το BOXNOW θα χρησιμοποιήσει το κατάλληλο compartment στο locker.

=====================================
PAYMENT MODES
=====================================

prepaid - Προπληρωμένο (πλήρωσε ήδη online)
cod     - Cash on Delivery / Αντικαταβολή

Στην εφαρμογή σου χρησιμοποιείς "prepaid" αφού πληρώνουν με Stripe.

=====================================
NOTES
=====================================

- Το Widget φέρνει αυτόματα updated lockers - δεν χρειάζεται API call
  από εσένα για τη λίστα lockers

- Το Backend API χρειάζεται ΜΟΝΟ για delivery requests, όχι για
  λίστα lockers

- Όλα τα errors είναι handled gracefully - αν το BOXNOW API
  αποτύχει, η παραγγελία θα συνεχίσει κανονικά

- Το tracking number αποθηκεύεται στο πεδίο 
  "boxnow_tracking_code" στον πίνακα orders

- Το OAuth2 access token caching είναι in-memory - σε serverless
  environments κάθε cold start θα πάρει νέο token (αυτό είναι OK)

- Το BOXNOW θα στείλει SMS στον πελάτη με PIN code όταν το
  πακέτο φτάσει στο locker

- Ο πελάτης έχει συνήθως 3-7 μέρες να παραλάβει το πακέτο
  πριν επιστραφεί σε εσένα
