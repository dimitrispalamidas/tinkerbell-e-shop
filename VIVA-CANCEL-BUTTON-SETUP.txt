=====================================
VIVA WALLET - CANCEL BUTTON SETUP
=====================================

Πώς να προσθέσεις κουμπί "Ακύρωση" στο Viva Checkout
-----------------------------------------------------

Το κουμπί "Ακύρωση" επιτρέπει στους πελάτες να επιστρέφουν
από τη σελίδα πληρωμής πίσω στο site σου.

=====================================
ΒΗΜΑ 1: ΕΝΕΡΓΟΠΟΙΗΣΗ ΣΤΟ VIVA PORTAL
=====================================

1. Σύνδεση στο Viva Portal:
   https://www.viva.com/el-gr (Production)
   https://demo.vivapayments.com (Demo)

2. Μετάβαση στην Πηγή Πληρωμής:
   Πωλήσεις → Online πληρωμές → Websites/Apps
   
3. Επιλογή της Πηγής σου:
   Βρες το "Tinkerbell E-Shop"
   Πάτα "Επεξεργασία" (Edit)

4. Scroll down στις "Ρυθμίσεις για προχωρημένους":
   (Advanced Settings)

5. Βρες την επιλογή:
   ☐ Κουμπί ακύρωσης (Cancel button)
   
6. ✅ Ενεργοποίησέ την (Check the box)

7. Αποθήκευση:
   Πάτα "Αποθήκευση" (Save)

=====================================
ΠΩΣ ΛΕΙΤΟΥΡΓΕΙ
=====================================

Μετά την ενεργοποίηση:

1. Στο Viva checkout θα εμφανιστεί κουμπί:
   "Ακύρωση" (Cancel) ή "Πίσω" (Back)

2. Όταν ο χρήστης πατήσει ακύρωση:
   → Ανακατευθύνεται στο Failure URL
   → Με παράμετρο: ?cancel=true
   
   Παράδειγμα:
   https://tinkerbell-e-shop.vercel.app/el/checkout?cancel=true

3. Το site χειρίζεται το cancel:
   ✓ Εμφανίζει μήνυμα: "Η πληρωμή ακυρώθηκε"
   ✓ Επιστρέφει στο Step 3 (Payment)
   ✓ Ο χρήστης μπορεί να δοκιμάσει ξανά
   ✓ Τα στοιχεία του διατηρούνται (localStorage)

=====================================
TESTING
=====================================

1. Ενεργοποίησε το cancel button στο portal

2. Κάνε test παραγγελία:
   - Πήγαινε μέχρι το payment step
   - Θα ανακατευθυνθείς στο Viva
   - Θα δεις κουμπί "Ακύρωση"

3. Πάτα "Ακύρωση":
   - Θα επιστρέψεις στο checkout
   - Θα δεις notification
   - Μπορείς να δοκιμάσεις ξανά

=====================================
FAILURE URL CONFIGURATION
=====================================

Βεβαιώσου ότι έχεις ορίσει το Failure URL:

Production:
https://tinkerbell-e-shop.vercel.app/el/checkout
https://tinkerbell-e-shop.vercel.app/en/checkout

Local Testing (με ngrok):
https://your-ngrok-url.ngrok.io/el/checkout

⚠️ ΣΗΜΑΝΤΙΚΟ:
- Το Failure URL πρέπει να είναι HTTPS
- Πρέπει να περιλαμβάνει το locale (/el/ ή /en/)
- Το site χειρίζεται αυτόματα το ?cancel=true

=====================================
TROUBLESHOOTING
=====================================

Το κουμπί δεν εμφανίζεται:
--------------------------
1. Έλεγξε ότι ενεργοποίησες την επιλογή
2. Refresh τη σελίδα του Viva Portal
3. Αποθήκευσε ξανά τις ρυθμίσεις
4. Περίμενε 1-2 λεπτά για propagation
5. Κάνε νέο test checkout

Το cancel δεν λειτουργεί σωστά:
------------------------------
1. Έλεγξε το Failure URL
2. Βεβαιώσου ότι είναι HTTPS
3. Έλεγξε το console για errors
4. Δες αν το ?cancel=true περνάει στο URL

=====================================
CODE IMPLEMENTATION
=====================================

Το Tinkerbell site χειρίζεται αυτόματα το cancel:

📄 app/(public)/checkout/page.tsx
Lines 69-83:

useEffect(() => {
  const urlParams = new URLSearchParams(window.location.search);
  if (urlParams.get('cancel') === 'true') {
    toast.info(
      locale === 'el' 
        ? 'Η πληρωμή ακυρώθηκε. Μπορείτε να δοκιμάσετε ξανά.' 
        : 'Payment was cancelled. You can try again.'
    );
    window.history.replaceState({}, '', window.location.pathname);
    setStep(3); // Stay on payment step
  }
}, [locale]);

Τι κάνει:
---------
✓ Ελέγχει για ?cancel=true
✓ Εμφανίζει friendly μήνυμα
✓ Καθαρίζει το URL
✓ Επιστρέφει στο payment step
✓ Διατηρεί όλα τα στοιχεία (localStorage)
