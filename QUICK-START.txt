🚀 GET STARTED IN 3 STEPS:

1️⃣  SETUP ENVIRONMENT
   Create .env.local file (see env.config.example for template)

2️⃣  RUN THE APP
   pnpm dev
   Open http://localhost:3000

3️⃣  CREATE ADMIN USER
   Option A - Using Supabase Dashboard:
   - Go to Supabase Auth
   - Create a new user
   - Go to SQL Editor and run:
     INSERT INTO admin_users (user_id, role) 
     VALUES ('user-id-here', 'admin');

   Option B - Using the script (requires service role key):
   npx tsx scripts/setup-admin.ts admin@example.com password123

📦 ADD SAMPLE DATA (Optional):
   - Go to your Supabase SQL Editor
   - Copy and run scripts/seed-sample-data.sql
