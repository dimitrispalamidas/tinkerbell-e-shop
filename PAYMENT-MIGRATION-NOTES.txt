=====================================
API CHANGES
=====================================

Old (Stripe):
------------
1. Create Payment Intent → Client Secret
2. Client-side Stripe Elements
3. Stripe handles payment in browser
4. Webhook confirms payment
5. Update order status

New (Viva Wallet):
-----------------
1. Create Payment Order → Order Code
2. Redirect to Viva Smart Checkout
3. Customer pays on Viva's secure page
4. Webhook confirms payment
5. Update order status
6. Customer redirected back to success page

=====================================
CHECKOUT FLOW
=====================================

Before (Stripe):
---------------
Checkout → Fill Info → Select Locker → 
Stripe Elements (on-page) → Payment Success → 
Webhook → Update DB → Success Page

After (Viva Wallet):
-------------------
Checkout → Fill Info → Select Locker → 
Create Viva Order → Redirect to Viva → 
Payment on Viva Page → Webhook → Update DB → 
Redirect to Success Page
